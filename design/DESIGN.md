# gPTP Studio DESIGN.md — 视觉与交互契约

原型（`design/prototype/`）与实现（`linux/src/main.cpp` DESIGN-TOKENS）都遵循本文件的语义、不变式与差异声明；**数值不在此复制**。

**真源分工**：颜色、字体栈、字号、圆角、间距与动效时长的具体值以 `design/prototype/shared.css` 为唯一真源（亮暗成对；"industrial blue" 主题自 1.0 演示层移植，宿主实现须与 CSS 对齐）；本文件只记语义名、用途与推导来源。改值改 CSS，改语义改本文件。

## Brief（2026-11-11 家族试点）

- **目标**：非从零重设计。在既有 industrial blue 体系上做 HIG 级打磨；让「同步状态一眼可判、硬件资格可信、证据链可回溯」这个专业主角在界面上站出来；界面达到可直接用于官网宣传的质量（实物截图验收后才能作对外素材）。
- **原型范围**（5 屏 × 亮/暗）：① 同步总览（英雄屏，含 offset 尖峰告警 + 失锁事件）② 链路与网卡（NIC 能力 + Preflight FAIL 态 + 实际时间戳路径）③ 角色与配置（四角色、ptp4l.conf 预览）④ 报文分析（密集报文表 + 解码树 + hex）⑤ 运行与日志（进程 / 聚合日志 / 预设 / 工程报告）。
- **Exit 条件**：5 屏关键状态齐（含失锁、告警、Preflight FAIL、冻结视图态）+ 交互逻辑定稿 + HIG 清单全过 + 用户评审通过。
- **不在范围**：新功能与路由/契约变更（不动 `rivet-schema.json` 与 RPC）；参考源、GM 调优两页的完整形态；商业定价/购买流程 UI；真实硬件截图；模拟器故障注入面板。

## 设计原则（HIG 内核 × 专业工具）

- **时间数据可读性**：一切时间量（offset / delay / freq / 时间戳）用等宽 + tabular-nums，右对齐，单位不换行；实时数字刷新不抖动版面。
- **状态一眼可判**：同步状态三级色语义固定——绿=锁定/通过，橙=漂移/警告，红=失锁/错误；颜色永远与文字双编码（SLAVE / UNCALIBRATED / FAIL），色盲与截图归档都可用。
- **能力 ≠ 精度**：NIC 能力、运行时实际 timestamp source、参考平台校准结果三类信息永远分开显示，绝不把纳秒分辨率包装成已校准精度。
- **证据可回溯**：告警关联报文号与引擎事件，报告/日志/诊断一键复制导出；工程师能从一条告警走到对应 Sync 帧再走回配置。
- **防错一致**：真实引擎启动前必先 Preflight；停止引擎、清空报文、删除预设属破坏性操作需确认；权限路径（CAP_NET_ADMIN 等）由 Doctor/Preflight 明示，绝不静默提权。

## 不变式

1. `accent` 蓝只给交互、选中与数据主序列（导航活动项、主按钮、选中行、链接、曲线主线）；绿/橙/红只给状态；禁止大面积状态色块（状态以徽标 + 文字呈现）。
2. 层级 ≤3 层表面：画布 < 卡片 < 悬浮/选中；深蓝渐变只属于顶栏品牌带，页面内部不再引入深色大底。
3. 所有时间数值等宽右对齐、单位固定（ns/µs/ms 按量级）；数字刷新不得改变版面布局。
4. 亮暗主题成对设计（GTK 宿主 `ColorScheme` 双套），不存在只有暗态的界面；告警在两态下对比度均达 WCAG AA。
5. 键盘可达走 GTK/焦点惯例（Tab 焦点链、F10 菜单、Ctrl+F 搜索；`Ctrl+1…6` 切页为本原型提出、实现待接），不自造 vim 式单键位；每个可点目标有可见焦点环。
6. 破坏性操作（停止全部、清空报文、删除预设）永远红色 destructive 且需确认；告警、报告、日志、诊断必可复制或导出。

## 2026-11-14 原型优化修订（覆盖上文同名视觉项）

本轮在 industrial blue 方向上优化五屏，不新增业务路由或 RPC；原型行为使用本地示例状态，不代表硬件测量或权限检查。实现尚未同步，本轮新 token 不再宣称与现有宿主逐值一致。

### 视觉契约

- 本轮起 `shared.css` 是唯一数值真源：画布、表面、主/辅助文字、顶栏品牌深蓝、交互蓝与主按钮、成功/警告/错误状态文字均亮暗成对定义在 CSS；角色为中性标签，不占用告警色。
- 字体层级（正文、表格与协议数据、页标题、指标）保留系统字体与等宽数据字体；间距节奏、卡片与控件圆角均见 CSS。
- 侧栏稳定展示五个已实现页面；参考源不显示为失效导航。专业桌面为主要环境，小窗口重排导航与面板，数据表格只在独立区域横向滚动。
- 统一 outline SVG 功能图标；状态反馈短促（见 CSS），支持 reduced-motion；保留亮暗主题、键盘焦点、语义表单和原生确认对话框。

### 流程与数据不变式

1. 示例会话统一为 enp3s0 上游、eth3 下游、Domain 0、边界时钟；历史失锁 14:02:11.002 至 14:02:14.202，持续 3.2 s，尖峰 1.24 ms。报文 #1029–1041 为关联证据。
2. 总览先显示当前同步，再显示历史已恢复事件；冻结曲线不停止引擎，冻结报文视图不停止采集。示例原型不假装有实时硬件数据流。
3. 草稿与已应用配置分别存储；配置变化会使旧检查结果失效；Preflight 的两项权限 FAIL 阻止真实引擎的新启动，不据此声称运行中的进程已停止。
4. 原型 Preflight 只重放已知示例结果，不提供“点击授权即通过”的伪修复；可切换模拟器体验完整本地启动流程，真实权限与硬件检查由后续宿主实现。
5. 告警→报文筛选→解码→关联日志→返回总览形成可操作路径。原始字节只在确有数据时展示，不虚构 Hex 或可用 pcap。
6. 停止引擎、清空报文和删除预设需确认；日志、配置、诊断与工程报告导出为实际本地文件。pcap 尚无真实接入，不伪报成功。
7. 示例存储仅浏览器本地；受限环境回退内存，不承诺跨会话持久化。现阶段不设计收费、档位、试用或许可入口，功能流程不受商业分层影响。

### 本轮退出范围

五屏及统一入口可编辑；本地交互与亮暗主题齐备；不涉及真实引擎、系统提权、硬件认证、完整参考源、商业购买或宿主代码。用户评审与实物实现仍须后续完成，不自动认定设计冻结。


## 2026-11-14 第二轮修订：角色语义与排障上下文

- 沿用 industrial blue 与上一轮亮暗 token；本轮调整流程与状态，不扩大硬件接入范围。
- GrandMaster 展示 MASTER 与授时配置，不将本机对外精度表述为已同步；被动监听展示 LISTEN ONLY，不启动 ptp4l/phc2sys，不出现本机 offset 或时钟调整指标。
- 从钟与边界时钟仅在原始历史会话展示测量快照；新模拟会话显示等待样本，不把启动成功等同于同步成功。停止会话不展示活动测量数值，原始历史快照仍可回溯。
- 历史失锁事件固定关联 2026-11-11、enp3s0、Domain 0 与原始边界时钟配置；报文、日志和 JSON/Markdown 报告不随当前草稿重写发生时信息。
- 草稿差异逐项展示，输入后立即刷新预览、差异及启动原因。空数值保留为空并阻断检查，不能隐式转为 0。修改使旧检查失效；重开页面需重新检查，不复用历史权限结果授权启动。
- 已应用配置与启动分开：运行中可编辑/检查草稿，但须停止旧会话后应用或启动；启动按钮旁始终说明阻断原因，真实服务未接入不能执行启动。
- 检查覆盖当前角色与端口：边界时钟检查两端；被动监听不要求 PHC 或时钟调整权限，但仍明确真实采集权限与服务缺口。网卡详情选择不修改草稿。
- 告警与报文进入日志时保存来路、筛选、选中帧及滚动位置，提供上下文返回。配对报文按源、Domain 与 sequence 匹配；配对对象被筛选隐藏时显式调整筛选使其可达。
- 区分报文库为空、筛选无匹配、未选择帧与缺少原始字节；清空报文不删除历史事件。报告披露本地证据保留数量。
- 原型边界集中在状态栏与接入说明，不在每个面板重复；工程报告保持现有范围。无真实引擎、权限或 pcap 服务接入。


## 2026-11-25 入口修正：五页统一为交互原型的薄壳

此前 `prototype/{overview,nics,config,packets,runtime}.html` 仍是 11-10 的静态稿（含已撤销的 Pro 徽标与「参考源」导航），而 `app.js` 的导航与回归脚本都指向它们，导致直接进入、主题切换、重开页面等 12 项回归失败，且 CI 不执行这组脚本。

- 唯一入口形态：`index.html`（`data-root`，根入口）与 `prototype/<page>.html`（`data-page="<page>"`）都是加载 `shared.css` + `app.js` 的薄壳，只提供 `#app`、确认对话框与 toast 容器；页面内容一律由 `app.js` 渲染，不在 HTML 里写第二份界面。
- 五个薄壳除 `data-page` 与 `<title>` 外逐字相同；改壳先改一处再同步其余四个。
- `tests/interactions.cjs` 进入 CI（`npm ci` + `npm test`）；该脚本仍只验证 DOM 交互，不代表浏览器渲染、布局或对比度已通过。
- 入口修正本身不改视觉；`shared.css` 当时未覆盖 `app.js` 的类名，已由同日「视觉落地」一节解决。


## 2026-11-25 视觉落地：`shared.css` 覆盖交互原型

规范修订：家族 `2026-11-20-minimal-family`；起始 SHA `4c30f6f`。此前 `shared.css` 仍是 11-10 静态稿的样式，`app.js` 使用的 92 个类名只有 9 个碰巧同名，浏览器实际渲染无样式。本轮重写 `shared.css`，不改 `app.js` 的结构、文案与流程。

**决策**

1. 强调色分三档：`--accent` 只作数据色（曲线、选中标记）；带文字的填充用 `--accent-fill`，强调文字用 `--accent-text`。原 `#2196F3` 白字与链接均只有 3.1:1，不满足不变式 4。
2. 状态色取可作正文的深度（亮色 `--ok #1B7549`、`--warn #8F5300`、`--danger #C62828`；暗色相应取浅），使徽标、日志级别、状态栏文字达到 4.5:1；`--mute` 同理加深，控件边界 `--line-control` 对底色 ≥3:1。
3. 默认密度为紧凑；字号取家族尺度 12 / 13 / 14 / 18 / 24；圆角 4 / 8 / 12；间距以 4 为基准。
4. 顶栏深蓝渐变按不变式 2 保留，为对家族「禁大面积装饰渐变」的已声明例外；页面内部不再有渐变或深色大底。
5. 删除已无消费者的静态稿组件样式（`.window/.headerbar/.pill/.item/.tbl/.stream` 等）。
6. 小窗口：≤1100px 面板收成单列、指标与角色两列；≤820px 侧栏变为横向导航，表格只在自身区域横向滚动。

**证据与未验证项**

- 无头 Edge 实际渲染：五页 × 亮暗 × 1440×1000 与 760×900 截图已逐张检视；`tests/interactions.cjs` 42 / 42。
- 对比度按 WCAG 相对亮度公式逐对计算，上表各档均达标。
- 未验证：真实鼠标/键盘交互下的焦点环与对话框焦点约束、200% 文字放大、读屏、Linux 字体实貌、GTK 宿主与原型的逐项对照。用户评审通过前不认定设计冻结，宿主实现不得据此对齐。
