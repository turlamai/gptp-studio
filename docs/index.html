替代零散工具链

把时间同步调试台， 收进一个窗口。

六页工作区

同步总览、链路与网卡、角色与配置、参考源、报文分析、运行与日志——每页盯住一件事，告警、报文与配置跨页互链。

GM / 从钟 / 边界时钟 / Listener

生成 ptp4l 配置并统一监督真实引擎生命周期。

PHC 与硬件时间戳资格检查

启动真实引擎前逐项 Preflight：驱动、链路、TX/RX 硬件时间戳、/dev/ptpN 与 CAP 能力路径；✓/✗ 清单与 FAIL 态一目了然，诊断可导出，绝不静默提权。

实时同步分析与根因

顶栏 6 枚实时 pills 常驻角色、端口、GM、offset 与 delay；锁定 / 漂移 / 失锁三级状态以颜色加文字双编码呈现，失锁与阈值越限即时横幅告警，并可从 offset 尖峰回看同时刻报文与观测性 BMCA 时间轴。

报文级关联

报文表逐帧保留纳秒级时间戳；Sync、Follow_Up、Announce、PDelay_*、Signalling 完整解码为缩进字段树，可对照 hex 视图与同 sequenceId 的关联报文逐字段核对。

无头 Doctor

生成默认脱敏的 NIC、PHC、linuxptp、权限与角色资格报告。

内置模拟器与故障注入

无需目标硬件也走同一条 encode/decode/store 管线；可注入 Sync/Announce 丢弃、Follow_Up 延迟、sequenceId 跳变与 offset 尖峰，对告警、BMCA 判读与报告做负向测试。

GM 运行时调优

经 pmc GRANDMASTER_SETTINGS_NP 在线修改 clockClass、clockAccuracy、timeSource 与 BMCA 优先级，无需重启引擎，服务 GM 接管与鲁棒性测试。

Wireshark 联动与工程报告

一键联动 Wireshark：实时（gPTP 捕获过滤器）或回放保留报文；导出脱敏的 JSON/Markdown 工程报告，含同步统计与报文证据。

平台契约

Linux 不是其中一个移植平台， Linux 就是产品本体。

其他操作系统明确不在产品支持范围内。没有同等 PHC、硬件时间戳和 linuxptp 路径的缩水移植，只会降低验证可信度与售后可支持性。

安装

第一步先运行 Doctor.

快速开始

# Debian/Ubuntu: from the latest release
sudo apt install ./gptp-studio-<version>-linux-amd64.deb
gptp-studio --doctor
gptp-studio

在 Ubuntu 24.04 LTS 上验证。安装到 /opt/gptp-studio，提供 /usr/bin/gptp-studio 命令与桌面入口。

Relocatable tar.gz

tar -xzf gptp-studio-<version>-linux-x64.tar.gz
cd <extracted-directory>
./gptp-studio --doctor
./gptp-studio

自包含，不在目录外安装任何内容。适合希望应用 payload 与系统包数据库解耦的实验室主机。

AppImage（任意发行版）

# pick the latest tag on the Releases page, e.g. v0.4.0
TAG=<latest-tag>
VERSION="${TAG#v}"
curl -fLO "https://github.com/turlamai/gptp-studio/releases/download/${TAG}/gptp-studio-${VERSION}-linux-x86_64.AppImage"
chmod +x "gptp-studio-${VERSION}-linux-x86_64.AppImage"
"./gptp-studio-${VERSION}-linux-x86_64.AppImage" --doctor
"./gptp-studio-${VERSION}-linux-x86_64.AppImage"

自带 GTK4 依赖闭包，比包管理器版本能跑在更老的宿主上；无需安装。

开始使用

从一次有效使用开始。

工程预览。规划有官方专业版，此处尚不提供购买或硬件精度保证。

仅支持 Linux，提供 x64 和 arm64 发布附件。Windows 和 macOS 不属于产品目标。真实抓包与 PHC 操作需要兼容硬件和适当权限。

先使用确定性模拟器，确认 GTK 窗口显示示例时钟和会话。

选择网卡或开启抓包前，阅读真实引擎配置与硬件资格说明。

随结果保存接口、驱动、时钟源、工具版本和抓包设置，便于其他工程师复现。

模拟器与 CI 证据不能证明网卡、硬件时间戳、linuxptp 互操作或定时精度已合格。0.4.0 起原始抓包导出和 Wireshark 回放已免费，工程报告仍有门禁；旧构建保留各自行为。
